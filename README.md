# Flutter_assignments

Flutter assignments and projects repository.

## Projects

- **Assignment 4 — Flutter Core Concepts Hub** ([`4/`](4/)): Multi-screen Flutter application demonstrating Form validation with `GlobalKey`, local assets & custom Google fonts (`Poppins`) in `GridView.count`, and implicit animations via `AnimatedContainer` with named routes navigation (`Navigator.pushNamed`).
- **ID Card App** ([`ID/`](ID/)): Digital Identity Card application built with Flutter following clean widget tree architecture.
- **Hello Flutter** ([`hello_flutter/`](hello_flutter/)): Starter Flutter project.
